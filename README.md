# Java25 Monorepo

Collection of coursework from the Agile Java Developer Class 2025:

- `java_enterprise` – Spring Boot application focused on basic API design  
- `design_patterns` – Refactoring and feature additions to a CLI game, with emphasis on SOLID principles  
- `social_media` – Hibernate, Docker & MySQL  
- `db_assignment` – Docker, databases, MySQL & JDBC (non‑Hibernate)

This repository showcases code from projects I’ve worked on, including group assignments where I acted as the main repository maintainer.
