- `design_patterns` – Refactoring and feature additions to a CLI game, with emphasis on SOLID principles (SOLO)   
- `social_media` – Hibernate, Docker & MySQL (GROUP)  
- `db_assignment` – Docker, databases, MySQL & JDBC (non‑Hibernate) (GROUP) 

This repository showcases code from projects I’ve worked on, including group assignments where I acted as the main repository maintainer.
