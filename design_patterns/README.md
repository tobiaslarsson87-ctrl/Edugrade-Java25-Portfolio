# Adventure Awaits – Textbaserat RPG
**Författare:** Tobias Larsson  
**Beskrivning:**  
Ett textbaserat rollspel byggt i Java där spelaren slåss mot monster, möter bossar, handlar i butik, uppgraderar utrustning och försöker överleva så länge som möjligt.
Fokus på förbättring av arkitektur och att följa SOLID-principer.
